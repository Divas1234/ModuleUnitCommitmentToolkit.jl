# Wasserstein DRO CCG

This note documents the renewable uncertainty model and the CCG solution path implemented in `tools/ccg`.

## Model Scope

Renewable uncertainty is represented by a finite wind scenario pool generated by:

```julia
winds, NW = genscenario(WindsFreqParam, 1; scenario_limit = N)
```

Each scenario is a normalized 24-period renewable availability trajectory. The CCG solver uses this pool as the finite support of the uncertainty distribution.

## Ambiguity Set

The DRO model uses a Wasserstein ambiguity set around the empirical scenario distribution:

```text
P = { p >= 0, sum(p) = 1, W(p, p0) <= epsilon }
```

where:

- `p0` is the empirical distribution over generated renewable scenarios.
- `epsilon` is controlled by `CCG_DRO_RADIUS`.
- Scenario distance is computed from normalized renewable trajectories.
- `CCG_WASSERSTEIN_POWER` controls the trajectory norm power.

## CCG Flow

1. Build an initial master with a small active renewable scenario subset.
2. Solve the active-scenario unit commitment master.
3. Fix first-stage commitment decisions.
4. Evaluate all candidate single-scenario recourse problems.
5. Solve the Wasserstein transport LP to obtain the worst-case distribution.
6. Add the most adverse inactive scenarios to the master.
7. Repeat until the gap tolerance or iteration limit is reached.

## Main Files

- `tools/ccg/driver.jl`: command-line entry point.
- `tools/ccg/ccg_solver.jl`: master/recourse CCG loop.
- `tools/ccg/ccg_helpers.jl`: scenario selection and subset helpers.
- `tools/ccg/dro_uncertainty.jl`: Wasserstein distance matrix, transport LP, and DRO objective.
- `src/renewables/renewable_simulation.jl`: renewable scenario generation.

## Run Example

From the repository root:

```bash
CCG_SCENARIO_LIMIT=20 \
CCG_INITIAL_SCENARIOS=3 \
CCG_SCENARIOS_PER_ITERATION=2 \
CCG_MAX_ITERATIONS=20 \
CCG_DRO_ENABLED=1 \
CCG_DRO_RADIUS=0.05 \
julia -t auto tools/ccg/driver.jl
```

For a quick smoke run:

```bash
CCG_SCENARIO_LIMIT=4 CCG_INITIAL_SCENARIOS=2 CCG_MAX_ITERATIONS=1 julia tools/ccg/driver.jl
```

## Useful Parameters

These values can be edited in `config/runtime_config.toml`.

| Variable | Default | Meaning |
|---|---:|---|
| `CCG_SCENARIO_LIMIT` | `20` | Candidate renewable scenario count. |
| `CCG_INITIAL_SCENARIOS` | `min(3, N)` | Active scenarios in the first master. |
| `CCG_INITIAL_POLICY` | `netload` | Initial scenario policy: `netload` or `first`. |
| `CCG_SCENARIOS_PER_ITERATION` | `2` | Worst inactive scenarios added each iteration. |
| `CCG_DRO_ENABLED` | `true` | Enable Wasserstein DRO objective and separation. |
| `CCG_DRO_RADIUS` | `0.05` | Wasserstein ambiguity radius. |
| `CCG_WASSERSTEIN_POWER` | `1.0` | Power used in scenario trajectory distance. |
| `CCG_PARALLEL_RECOURSE` | auto | Evaluate recourse scenarios in parallel when Julia has multiple threads. |
